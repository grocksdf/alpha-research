# V0.3.4 — Windows 与 UTF-8 兼容性

用户上传的 V0.3.3 ZIP 在应用前通过了 `MANIFEST.sha256` 的全部 44 项校验。
随后在 Windows、Python 3.11 环境运行测试时发现两类平台兼容问题：

1. `Path.read_text()` / `write_text()` 未指定编码，Windows 中文环境会使用 GBK，
   因而无法读取 UTF-8 的中文 TOML、JSON 和报告。
2. 原子更新探测记录时以只读描述符调用 `os.fsync()`，Windows 返回
   `OSError: [Errno 9] Bad file descriptor`。

## 修复

- 生产代码中的配置、规则、目录、报告、预注册、探测记录和追踪输入显式使用 UTF-8。
- 测试读取由生产代码生成的 UTF-8 文件时同样显式使用 UTF-8。
- 原子写入完成后，以 `r+b` 打开临时文件并执行 `fsync`，再原子替换目标文件。

## 验证

- Python 3.11 / Windows
- `python -m unittest discover -s tests -v`
- 128 / 128 通过
