# AlphaResearch v0.8.2 — 自主发现能力分析（验收 B）

本报告回答：**系统是否真的自主发现了 Alpha？** 区分「由 LLM 输出」与「金融创新」，并如实标注哪些是传统已知机制、哪些是真正的新组合。

---

## 1. 命题与判定标准

「自主发现 Alpha」不能仅凭 `generator=llm` 或「公式由 LLM 产出」来判定。本报告的判定标准：

1. **来源可追溯**：每个假设/表达式必须能追溯到真实 LLM 的原始结构化提案（`source=authenticated_llm_tool_call` + response_id/tool_call_id/payload_sha256）。
2. **无固定模板回退**：不存在预设候选公式、固定因子家族或 fallback 生成器。
3. **机制独立性**：多个假设的机制标签两两互异，非同一公式的窗口/参数变体。
4. **合法性**：表达式通过确定性 AST/字段/算子校验。
5. **进入实验**：表达式实际进入 Demo 模拟。
6. **区分已知 vs 新**：传统教科书机制 ≠ 金融创新。

---

## 2. 来源审计

| 项 | 结果 |
| --- | --- |
| 假设来源 | 4 条，全部来自 explorer 角色真实 LLM 工具调用 |
| 表达式来源 | 全部来自 worker 角色真实 LLM 工具调用 |
| 来源标记 | `source = "authenticated_llm_tool_call"`，含真实 response_id/tool_call_id/payload_sha256 |
| 固定模板回退 | **无**（`automatic_fallback=false`；源码无 `_demo_fixtures`/预设公式；`mechanism_label` 无 enum = 自由文本机制） |
| 伪造修复 | 无（无预设答案、无硬塞修订） |

**结论**：所有假设与公式均源于真实 LLM 结构化提案，来源证明完整，无固定模板回退。

---

## 3. 独立经济机制（第三轮 v3）

4 条假设，4 个互异机制标签：

| # | mechanism | 说明 | 字段 | 证伪条件 |
| --- | --- | --- | --- | --- |
| 1 | Close-to-VWAP 偏离回复 | 收盘价 vs 当日 VWAP 的正偏离反映单边激进订单流，后续应反转 | close, vwap | IC 可靠为正、或控制 5/10 日收益后预测力消失则证伪 |
| 2 | 成交量条件化短期反转 | 低成交量极端收益反转更强 | volume, returns | 反转强度不随成交量条件变化则证伪 |
| 3 | 隔夜-日内收益拉锯 | 隔夜累积收益 vs 日内收益的价差 | open, close | 合并 IC 为负、或两腿都过不了 20 日总收益控制则证伪 |
| 4 | Amihud 非流动性溢价 | 高非流动性低成交量股票溢价 | volume, returns | —— |

**机制多样性评价**：4 条机制两两互异，覆盖微观结构（VWAP 偏离、隔夜/日内）、行为反转、流动性溢价等不同族，**非同一公式的窗口/参数变体**。

**必须明确**：这些全部是**金融文献中的已知教科书机制**（Hasbrouck 1991、Kyle 1985、De Bondt & Thaler 1985、Jegadeesh & Titman 1993、Amihud 2002 等）。模型为它们配上真实引用即可说明来源，**不得声称是金融领域从未出现过的新因子**。真正可称为「新组合」的，是 worker 产出的**表达式层面的组合变体**（如把 VWAP 偏离与 subindustry 中性化、成交量 rank 权重组合），但这些组合的**经济增量价值尚未被任何真实市场数据验证**。

## 4. 表达式与合法性

| 指标 | 值 |
| --- | --- |
| worker 产出表达式（含变体） | 6 次 `v08_formula_validation_attempt` |
| 通过确定性合法性校验并入队 | 3（`v08_candidate_queued=3`） |
| 进入 Demo 模拟 | 2（trials=2） |
| 停在 queued 未模拟 | 1 |
| 非法公式（触发修复） | 0（未触发 P0-3 自我修复路径） |

worker 产出的代表性合法表达式：

```
-group_rank(ts_mean(close / vwap - 1, 10), subindustry)
-ts_rank(ts_sum(returns, 5), 20) * (1 - group_rank(ts_mean(volume, 5), subindustry))
```

字段全部落在授权目录内（9 个字段），算子通过 BRAIN catalog 校验。

## 5. 是否「根据结果提出新修订」？

| 检查项 | 结果 |
| --- | --- |
| Critic defer 生成修订 | ✅ 1 次（`v08_revisions` 项 `c4578eaf`，depth 1，带完整理由） |
| defer 理由质量 | 实质内容（要求修正 ts_delay 对齐误解、预登记隔夜/日内两腿分别报告等） |
| 修订落地为新表达式 | ❌ 状态 `pending`，未被后续 Worker 消费 |
| 父子假设链 | ❌ 4 条假设 `parent_id` 全 None |
| 基于模拟结果的修订 | ❌ 2 个模拟结果（synthetic）未反馈到新一轮假设 |

**结论**：反馈修订的**入口机制被实证触发**（Critic defer → source-linked revision），但**未走完整「修订→再验证→再模拟」闭环**，也未形成父子假设链。原因是第三轮在 Playbook 固化阶段被 fail-closed 拦截，后续批次未执行。

---

## 6. 结论

- **自主发现（来源真实、机制互异）**：✅ **实证**。4 个互异机制、真实 LLM 来源、无模板回退。
- **合法表达式产出**：✅ **实证**。3 个候选通过确定性校验。
- **进入实验**：✅ **部分**。2 个候选完成 Demo 模拟（synthetic）。
- **反馈驱动修订闭环**：❌ **未实证**。defer 入口真实，但未走完整闭环。
- **金融创新**：❌ **不能声称**。全是已知教科书机制；组合变体的经济增量未经真实市场数据验证，Demo 合成的 Sharpe/Fitness 不代表真实收益。

**一句话**：系统确实「自主生成了来源可溯、机制互异的候选」，但**尚未证明「自主发现了有效 Alpha」**——缺真实 BRAIN 模拟验证，且所有机制都是已知因子，不能称金融创新。
